# 學習圖片目錄

共 170 張精選原始檔，約 106.2 MiB。最新兩板是支承適用性診斷，明標前輪舊渲與本輪舊幾何重渲，沒有新髮形；歷史圖原樣保留，仍本地待同步。

## 來源與解讀

- `reference/character-three-views.png`：使用者提供的角色原圖，經使用者允許加入公開學習紀錄。不是 DOTS 這次製作的模型成果。
- 其他圖片：DOTS 學習實驗保存的實際渲染、比較板或自製分析圖；部分含上述原圖裁切／輪廓標註。
- `hair-occlusion-analysis`、`hair-root-research` 是原圖分析，不是新渲染；`head-cheek-research`、`head-evidence-audit` 包含舊渲染輪廓分析，不是新模型。
- 草模、機制練習與失敗實驗不代表完成角色，結論與限制請看各篇 NOTES。
- 不宣稱擁有第三方角色設計或教材權利；無額外授權轉載第三方媒體的含意。
