# 袖口接觸摩擦：先確認有接近接觸區，再比較參數

2026-10-28 23:06 UTC。**摩擦0/80有小幅幾何差異，外觀卻幾乎相同；不能靠增加摩擦解決方角、過量皺摺或證明捲袖受到真實支承。不整合人物。**

## 實讀來源
- Blender官方Collision 3.4：https://docs.blender.org/manual/en/3.4/physics/collision.html 。直接4.3頁面402，搜尋索引返回3.4完整相關文字，實讀碰撞對象須啟用、修改設定後須重算、厚度是碰撞區及Soft Body and Cloth段。未看圖片或影片。
- Blender官方CollisionSettings API 4.4：https://docs.blender.org/api/4.4/bpy.types.CollisionSettings.html 。實讀索引返回cloth_friction、friction_factor、thickness_outer定義；本機4.3.2 RNA另確認cloth_friction是布料碰撞摩擦，friction_factor是粒子用。未假稱成功開啟4.3官方API頁。
這些是求解機制資料，不是同款袖子美術教程。0/80是敏感度極端值，非真實布料／皮膚係數校準。

## 方法
沿用上一輪肩端與回折末端列固定的模型。兩次從首幀重新建模求解，僅改手臂碰撞物件cloth_friction為0及80；餘量0.108、固定組、剛度、65幀、重力、自碰撞、.004碰撞外厚及.003布料距離都不變。沒有釋放末端固定列，所以本實驗不能驗證袖口能否靠摩擦自行停留。

每幀在不修改求解器的情況下，讀取評估後袖面頂點到實際手臂表面的最近距離。距離<=.008作「接近碰撞區」診斷，而不是物理接觸力證明；點採樣包含細分與厚度，不能用頂點數推算接觸面積。

## 首次失敗與修正
第一次為取得求解原面，每幀切換Subdivision/Solidify顯示；這會失效快取，結果回到平滑初態。0/80完全相同是無效實驗，不採用為摩擦結論。已保存failed-diagnostic-invalidation的模型、腳本與圖。
修正後不在逐幀診斷中切換任何修改器，保持被動讀取，重新從首幀跑兩組。最新兩組都恢復壓縮皺褶。最後才固定結果網格供可攜恢復，live快取不宣稱已烘焙。

## 觀察與有限證據
- 兩組均有47/65幀出現<=.008的採樣點。全程最小距離約.00423與.00443；最多27與36個近距離樣本（每幀17472點）。這只支持存在局部近接觸，不是全曲面接觸檢測。
- 2208個同索引求解頂點最終最大位移差約.0218，RMS約.00298。固定四角渲染可見外觀差異很小，方角與聚摺仍在；數據不是美術進步。
- 不能說摩擦不起作用，也不能說80較好；極端值尚不能顯著解決目前形體問題。自碰撞摩擦未改，不能將布對布與布對手臂混為一談。
- 原圖等比裁切，未校準像素/相機；未做全表面自交、變形動畫驗收。

## 學到／下個缺口
學到分清布料碰撞摩擦與粒子參數，以及量測本身不可重置求解器。先確認近接觸，才能解釋摩擦試驗。下一步不繼續盲調摩擦：要找實際捲袖如何靠折層、接觸與布料鬆量維持，而本模型仍由人工末端固定支承。應以可見的真實捲袖/作者裁片步驟拆解主要摺面，再決定是否解除該固定。所有舊版與完整人物04保留。
