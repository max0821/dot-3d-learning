# 小練習：截面凸度與扭轉，還是觀看方向？

## 結果先說
B1增加凸度後，側面有較強的體積明暗；B2再扭轉後輪廓稍有改變。兩者都保留束間谷，但**都沒有充分解決原後斜角的薄片／折片感，不整合全頭**。

本輪更重要的發現：原後斜鏡頭幾乎沿髮束長軸看。兩束的根→尖方向與視線只差 **8.3°、6.0°**；新增前斜診斷則是 **79.2°、82.9°**。同一B0在前斜角已顯出完整長度。因此不能把原後斜角的強烈縮短全歸因於截面太薄，也不能換鏡頭後宣稱模型進步。

## 讀到什麼
已讀 Danny Mac 的公開原文 [How to Model Hair in Blender](https://blog.cgcookie.com/posts/how-to-model-hair-in-blender/) 中關於髮束截面、控制點扭轉、較寬較扁的中型髮束與多角度檢查段落。這支持把「截面形狀」與「截面方向」分開控制，不代表作者要求這次的凸度或角度數值。沒有觀看完整付費課程。

嘗試讀Blender官方曲線Geometry／Control Points頁時，工具返回402，故沒有把其全文當成已讀證據。實作採用可檢查的網格頂點與切線軸旋轉，不宣稱操作了作者完整曲線流程。

## 假設與受控變因
- **B0：** 上輪B的原始98頂點網格完整保留。它是「淺凸／近扁基準」，不是數學上的全平面；原有微凸也沒有歸零。
- **B1：** 只增加分支中段截面凸度。固定中脊控制點，把截面兩側沿X退回；峰值額外偏移0.070，根端與尖端衰減為0。沒有改兩束路徑或再膨起根部。
- **B2：** 在B1上單獨增加繞局部切線的截面扭轉，峰值28°；根與尖端扭轉為0。不能把B0→B2差異單獨歸因於凸度。
- 36個根區控制點、2個尖端及12個中脊控制點的最大位移均為0；網格連接、厚度0.018、細分、材質、光與每一列相機均相同。
- 以上是**控制網格／設計路徑**的不變量。鄰點變動可影響細分後的曲面，並未宣稱所有評估後表面點完全不動。

## 實際觀察
| 檢查 | B1：只加凸度 | B2：再加扭轉 |
|---|---|---|
| 側面 | 底緣陰影更明顯，片身較有起伏；谷仍開放 | 上下邊緣略轉，谷仍可讀 |
| 原後斜角 | 仍強烈縮短，尚像折片 | 改善有限，沒有變成自然髮束 |
| 背面／前斜診斷 | 仍可看見片狀邊緣 | 有些區域更像捲邊，不能稱成功體積 |
| 根部 | 沒有重長成兩個圓鼓根 | 根區未改，但原直邊問題也未解決 |

未觀察到明顯新增頭皮穿插；另以分支控制點射線作有限檢查，每版14個命中樣本都沒有落入頭皮。其他樣本超出該射線的頭部截面；這**不是完整細分曲面自交／穿插證明**。

## 學到什麼／尚未解決
1. 截面凸度能改變明暗和邊緣，但不是「看起來薄」的通用解藥。
2. 固定路徑下，接近髮束長軸的鏡頭必然大幅縮短長度；先分清投影縮短與真正缺乏體積。
3. 中段變凸與扭轉沒有消除寬根直邊及折片感；仍不符合自然尖髮的多角度要求。
4. 下一個問題應先選定不正對長軸的診斷角度，檢查截面是否捲成邊，再只調一個截面參數；不要靠換鏡頭或加更多髮束宣稱改善。
