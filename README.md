## 目前的學習位置

目前在頭髮階段：主髮量、可見剪影、層次、髮束根部與髮流。頭形暫留 `iteration04`；可見頰顎保留，但被遮住的顱頂與後腦未驗證。衣物筆記是之前的研究存檔，不代表跳過頭髮階段。

最新更正是 [H1輸入契約撤回](experiments/forelock-support-h1/NOTES.md)：前輪規格誤把audit B當有限根邊界的輸入。血緣核對後撤回，未進行射線或接根；已知雙尖不是本輪新學習，沒有可交付新模型／圖。原圖吻合與三維可用性分開驗收的原則仍保留。

最新局部練習是 [單尖面片最近表面適配](experiments/forelock-surface-strip/NOTES.md)：新有限根邊界成立，但整束Closest投影破壞可見弧，縮成小額片，失敗不採用。學習界線是支持區貼合與自由尖髮分工，不是已學會自然根。

最新限制補充是 [可見接點與支承門檻](experiments/forelock-support-gate/NOTES.md)：換現有主束／鄰束也無接收面，撤回與舊失敗重複的餘量延伸。這輪只有研究及不改形診斷，沒有新模型／圖；下一問題改為寬前殼與主量的共同面轉向，不再反覆改同一高邊的投影目標。

最新來源研究補充了共同前髮面、整組變形與長髮法線修飾的區別。作者成形線框／渲染不是建構步驟；原教學播放未成功，尚不能開始包覆實作。沒有新模型／圖，細節見上述方法限制附錄。

最新主量研究比較了「寬扁管作底量後合併重排」與「保留獨立主束」的選法。只實讀作者文字，未取得中間圖，無新模型／圖；見[主量來源補充](experiments/hair-mass-overlap-research/NOTES.md)。

最新復習是[原生Pinch收尖小樣](experiments/mass-layer-separation/NOTES.md)：正面尖、斜角與端視卻形成薄鰭，失敗不採用；新兩板是真實局部渲染，不是角色改善版。

## 這裡刻意保留失敗

- 封閉髮束有體積，仍可能像板片或葉片。
- 正面輪廓接近，側面仍可能錯、內部仍可能穿模。
- 增加束數、頂點數、版本數，不等於理解形體。
- 原圖中的陰影、遮擋與非標準側圖，不能硬當精確幾何。
- 讀到文字、看見圖解、取樣影片影格、看完整操作，是不同證據。
