## 目前的學習位置

目前在頭髮階段：主髮量、可見剪影、層次、髮束根部與髮流。頭形暫留 `iteration04`；可見頰顎保留，但被遮住的顱頂與後腦未驗證。衣物筆記是之前的研究存檔，不代表跳過頭髮階段。

最近一個工具練習是 [Elastic Snake 根遮罩](experiments/elastic-snake-root-mask/NOTES.md)：遮罩能保護根區，但延伸後仍圓鈍、體積改變，沒有形成符合參考的髮束。**工具機制驗證，不等於造型完成。**

## 這裡刻意保留失敗

- 封閉髮束有體積，仍可能像板片或葉片。
- 正面輪廓接近，側面仍可能錯、內部仍可能穿模。
- 增加束數、頂點數、版本數，不等於理解形體。
- 原圖中的陰影、遮擋與非標準側圖，不能硬當精確幾何。
- 讀到文字、看見圖解、取樣影片影格、看完整操作，是不同證據。

## 公開版邊界

此批是**文字知識庫**：不包含原始角色參考圖、`.blend`、GLB、渲染對照、第三方教學圖片或原作者程式。各筆記描述的是當時紀錄，公開整理沒有重跑模型或重新驗證所有來源。未附檔案只以名稱描述，不提供不存在的下載連結。

附帶一個自製、只用 Python 標準函式庫的[倉庫驗證腳本](scripts/check_repository.py)，可檢查本地 Markdown 連結、筆記數量與明顯內部識別碼。它不驗證 3D 品質。第三方來源權利歸原作者；本文只連結並摘要，未重新授權來源素材。
